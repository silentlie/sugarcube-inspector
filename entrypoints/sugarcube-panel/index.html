Inspect live variables

In the Elements panel, select the SugarCube Story or SugarCube Temporary sidebar tab.

Those panes use Chrome's own expandable JavaScript object inspector: no snapshots, no custom cloning, and no extension debugger attachment.

The Console can still inspect or modify the same live objects using SugarCube.State.variables and SugarCube.State.temporary.
